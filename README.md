# LINK — читайте книгу на двух языках

Однофайловое веб-приложение (PWA) для параллельного чтения текста на двух языках, с ИИ-помощником под рукой: перевод выделения, комментарий к отрывку, сравнение перевода с оригиналом, озвучка вслух и краткое саммари прочитанного. Работает целиком в браузере, без сервера и backend — все файлы читателя остаются на его устройстве.

---

## Предыстория

LINK не задумывался как отдельный продукт — он вырос из конкретной практической задачи: удобно прочитать одну книгу.

**1. «Кто идёт?»** (`Who_is_it.html`)
Всё начиналось с повести Джона У. Кэмпбелла «Who Goes There?» («Кто идёт?») — того самого текста, что лёг в основу фильма «Нечто». Первая версия была самой обычной read-only HTML-страницей под одну конкретную книгу: текст вшит прямо в файл, минимальная вёрстка, и главная фишка — глоссарий: непонятные слова и обороты снабжены всплывающими подсказками с переводом/пояснением прямо по тексту.

**2. День/ночь** (`Who_is_it_day_night.html`)
Следующий шаг — переключатель светлой/тёмной темы для комфортного чтения вечером. Сама концепция «книга внутри HTML-файла с глоссарием» осталась прежней.

**3. Первый настоящий «читательский движок»** (`index-1.html`)
Дальше версия под ту же книгу разрослась в полноценную читалку: закладки, синтез речи (Web Speech API) для чтения вслух, ИИ-комментарии через Groq API, тёмная тема, свой глоссарий — но всё ещё **жёстко привязано к одному тексту**: сама книга была зашита в файл, поменять её без правки кода было нельзя.

**4. Идея обобщить: рождение LINK**
Возник закономерный вопрос: а зачем привязываться к одной книге, если движок для чтения (закладки, TTS, тема, ИИ-подсказки) уже универсален? Так появился LINK — то же самое читательское ядро, но без вшитого текста: пользователь сам загружает файл(ы), какие хочет. Специализированный глоссарий под конкретную книгу ушёл — вместо него общая функция «Перевод» для любого выделения плюс «Комментарий» от ИИ. Добавилась вторая колонка — можно параллельно загрузить оригинал, чтобы сравнивать перевод с исходником прямо по ходу чтения (кнопка «Оригинал» в тулбаре выделения).

**5. От одной книги к библиотеке**
LINK продолжил расти уже как самостоятельный проект: разбор `.fb2`/`.txt`, затем `.epub` и `.zip`-архивы (JSZip), затем `.pdf` (pdf.js, эвристическая реконструкция абзацев по координатам текста) и `.docx`/`.html` (последние — вообще без новых зависимостей, `.docx` переиспользует уже подключённый JSZip). Появилась «Моя полка» — персистентное хранилище нескольких книг в IndexedDB с автосохранением прогресса чтения, PWA-манифест и service worker для установки на экран и офлайн-запуска оболочки приложения.

Итог: из одноразовой странички под конкретную повесть получился универсальный, ничем не привязанный к конкретному тексту читатель с ИИ-инструментами — тот, что описан ниже.

## Возможности

- **Два режима загрузки.** «Читать» — один файл. «LINK» — два файла (текст для чтения + оригинал), с быстрым свапом местами (⇄).
- **Поддерживаемые форматы:** `.txt`, `.fb2`, `.epub`, `.pdf`, `.docx`, `.html`/`.htm`, а также `.zip`-архив с `.txt` или `.fb2` внутри.
- **Разбиение на главы** — лёгкое, без сложного анализа: по заголовкам `<title>`/`h1-h4`/стилям `HeadingN` там, где формат это позволяет (FB2, EPUB, DOCX, HTML), либо по regex-паттерну «Глава/Часть/Chapter/Part» для голого текста (TXT и текст, извлечённый из PDF).
- **Оглавление** — выезжающая панель с быстрым переходом по главам.
- **Закладки** — по абзацам, с панелью со списком и переходом.
- **Прогресс чтения** — восстанавливается автоматически при повторном открытии книги.
- **«Моя полка»** — до 15 книг одновременно (LRU: при превышении лимита вытесняется книга, которую дольше всего не открывали), файлы книг лежат в IndexedDB, а не в localStorage (там для этого маловато места).
- **Дедупликация по содержимому.** Ключ книги на полке считается по хэшу текста всех абзацев, а не по имени файла — один и тот же текст, загруженный напрямую или из другого контейнера (например `.zip`), не создаёт дубликат.
- **Тёмная/светлая тема**, регулировка размера шрифта.
- **Озвучка вслух** — Web Speech API с автоопределением языка абзаца (`detectLang`) для правильного голоса.
- **ИИ-инструменты по выделению текста** (через Groq API, ключ вводит сам пользователь и хранит только у себя в браузере):
  - 🌐 **Перевод** — выделенного слова или отрывка;
  - 💬 **Комментарий** — литературный/контекстный разбор отрывка;
  - 📄 **Оригинал** — поиск и цитирование соответствующего места в оригинале (при загруженном втором файле), с ограничением зоны поиска до ±1 главы, чтобы не гонять по всей книге и не путать модель;
  - 📋 **Саммари** — краткое ИИ-саммари прочитанного участка.
- **PWA:** `manifest.json` + `sw.js` — приложение можно установить на экран телефона, оболочка (сам интерфейс) кэшируется и открывается офлайн; текст книги в кэш оболочки не попадает специально — он либо в IndexedDB, либо загружается пользователем заново.
- Полностью тёмная приватность по умолчанию: ни один файл книги никуда не отправляется, кроме явно выделенного пользователем фрагмента текста — и то только в момент запроса к Groq, вручную инициированного кнопкой.

## Стек

- Чистый HTML/CSS/JS, без сборки и фреймворков — всё приложение в одном `index.html`.
- [JSZip](https://stuk.github.io/jszip/) — для `.zip`, `.epub` и `.docx` (все три — ZIP-контейнеры).
- [pdf.js](https://mozilla.github.io/pdf.js/) (Mozilla, legacy-сборка) — для `.pdf`, подключается лениво через динамический `import()` только когда PDF реально открыт.
- Web Speech API (`speechSynthesis`) — озвучка, без внешних сервисов.
- [Groq API](https://groq.com/) (`openai/gpt-oss-120b`) — все ИИ-функции.
- IndexedDB — «Моя полка»; `localStorage` (с safe-обёрткой на случай приватного режима/`file://`) — настройки, прогресс, закладки текущей книги, API-ключ.
- Service Worker — офлайн-кэш оболочки приложения (не текста книг).

## Структура проекта

```
index.html            — всё приложение: разметка, стили, вся логика
manifest.json          — PWA-манифест (иконки, цвета, имя)
sw.js                  — service worker: кэш оболочки приложения
jszip.min.js            — библиотека для .zip/.epub/.docx
pdf.min.mjs             — pdf.js (основной модуль)
pdf.worker.min.mjs      — pdf.js (воркер для парсинга PDF)
icons/                  — иконки PWA (icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png)
```

Все файлы должны лежать рядом, в одной папке — пути в `index.html`/`sw.js`/`manifest.json` относительные.

## Как запустить

PWA (service worker, установка на экран) работает только при обслуживании по `http(s)` — на локальном файле (`file://`) браузер не даёт регистрировать service worker, это ожидаемо и некритично: само чтение работает и без него, просто без офлайн-режима и установки на экран.

Варианты хостинга:
- Любой статический хостинг (GitHub Pages, Netlify, Vercel, Cloudflare Pages) — просто выложить содержимое папки как есть.
- Локально для разработки — любой простейший статический сервер (`python3 -m http.server`, `npx serve` и т.п.), открытый по `http://localhost`.

### Groq API-ключ
ИИ-функции (перевод, комментарий, оригинал, саммари) требуют ключ Groq API — вводится один раз через ⚙️ в читалке и хранится только в `localStorage` браузера пользователя. Без ключа доступны: чтение, закладки, оглавление, озвучка, темы, полка — всё, кроме ИИ-кнопок.

## Известные особенности и ограничения

- **PDF** — не текстовый формат, а «нарисованные» символы с координатами. Реконструкция абзацев эвристическая (группировка строк по Y-координате, разрыв абзаца — по увеличенному межстрочному промежутку). Хорошо работает на простой одноколоночной вёрстке (обычный роман); на сканах без текстового слоя не сработает вообще (нужен OCR — не реализован), на сложной многоколоночной вёрстке текст может перемешаться по порядку строк.
- **DOCX** — заголовки глав определяются только по стандартным стилям Word (`Heading1`, `Heading2`, ...). Если текст в документе не размечен стилями — вся книга придёт одной главой без заголовка.
- Старые записи «Моей полки», сохранённые до перехода на дедупликацию по содержимому, используют старый ключ (по имени файла) и не совпадут с новым — не удаляются автоматически, вытесняются лимитом или удаляются вручную.
- Лимит полки — 15 книг (LRU-вытеснение) — значение по умолчанию, легко меняется в коде (`SHELF_MAX_ENTRIES`), не техническое ограничение IndexedDB.

## Не реализовано (осознанно)

- `.mobi`/`.azw` — проприетарный бинарный формат Amazon без нормальных браузерных парсеров.
- `.doc` (старый бинарный Word) — не XML, а бинарный формат; при необходимости — конвертация в `.docx` перед загрузкой.
- OCR для сканированных PDF — отдельная по объёму фича (Tesseract.js и т.п.), добавляется только при реальной необходимости.
